### Agent 擅长扩展，不擅长压缩

Agent 非常擅长扩展一个已有的任务，做起来也很轻松。比如在已有的框架下增加一个新的功能，或者把一个简短的需求展开成详细的实现计划——这种"从少到多"的工作，agent 几乎都能胜任。

但写作和审美是密度特别高的事情。它们的本质不是扩展，而是压缩：把一堆模糊的想法压缩成更少的、每句话都有重量的文字；从无数可能的设计里挑出那个让人眼前一亮的版本。这种"从多到少"的判断，需要 taste，需要一个明确的视角，需要知道哪些东西必须留下、哪些必须舍弃。

Agent 在这件事上很难做好。它能模仿你的语气，但模仿不出"为什么这一句要写、那一句不要写"的判断。结果就是它生成的文字句句通顺，整体却扁平——什么都说了，又什么都没说重。

所以现在我对自己的分工是：把扩展类的工作（写代码、查资料、生成草稿、跑实验）交给 agent；把压缩类的工作（写作、做设计判断、决定方向）留给自己。
